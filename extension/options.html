LinkDrag

把任意链接在当前页浮出预览：多窗口、画中画、阅读模式、悬停小窗、只读快照、嵌套预览与会话恢复；拖拽图片直接查看高清原图。

安装成功。 打开任意普通网页，按住链接拖动、长按、Alt+点击，或把鼠标停在链接上约 600ms，即可看到预览。工具栏图标提供当前站点开关和最近预览。

扩展级开关

这些开关对所有网站生效。更细的动画、主题、阅读模式与触发阈值在「页面内完整设置」里。

每行或逗号分隔；子域名会一并暂停。暂停后设置/说明窗口仍可打开。

扩展更新

每次启动浏览器检查 GitHub 最新发布。只提示是否有新版，不会自动下载；点击更新会打开 GitHub 发布页。

公开仓库可以不填；填写 GitHub Personal Access Token 可避免 API 限流。令牌只保存在本机 chrome.storage.local，不会注入网页。无需 repo 写权限，只需读取公开仓库。

这一版做了什么

原生扩展能力

  • 后台 Service Worker 跨域抓取，不受页面 CORS 限制
  • 右键菜单直接预览链接 / 选中网址
  • 工具栏快捷开关、站点暂停、窗口数徽标
  • 扩展命令 Alt+Shift+L，可在浏览器里改键
  • 扩展更新后可按需向旧标签页补注入内容脚本

核心增强

  • 预览内跳转后，阅读模式 / 快照 / 新标签页使用当前地址
  • 拖拽图片自动挑选最高清候选，支持缩放、平移与会话恢复
  • 悬停从 A 链接快速移到 B 链接不再被旧定时器吞掉
  • 预热去重键会随移出/收起重置，不再“第二次不预热”
  • 设置/说明窗口不再占用 maxWindows 名额
  • 抓取 4xx/5xx、超时、空壳与跨域错误分别说清楚

安全边界

  • 阅读模式与快照均禁用脚本；快照额外移除音视频、表单和内嵌播放器，只读渲染
  • 不接管中键：中键仍由浏览器开后台标签页
  • 仅对媒体 CDN 请求补充 Referer；不修改页面响应头，不绕过 X-Frame-Options/CSP 嵌入限制
  • 页面内设置使用 closed shadow root，页面脚本无法读取已保存的 API Key
  • 消息带命名空间、iframe source、token 与 navSeq 校验，并对嵌套预览限流
  • 受限页面（chrome://、扩展商店、PDF 查看器）无法注入，这是浏览器限制

常见问题

为什么有些网站仍然不能直接嵌入？

站点通过 X-Frame-Options 或 CSP frame-ancestors 拒绝被嵌入，扩展不会篡改网站响应头。脚本会自动用后台权限抓取 HTML，渲染成只读快照；纯 JavaScript 渲染的 SPA 可能只剩空壳，这时提示条会给出「在新标签页打开」。

为什么 chrome://、edge:// 和扩展商店没有预览？

这些是浏览器的受保护页面，任何扩展都不能向其中注入内容脚本。PDF 内置查看器同理。

file:// 页面怎么启用？

在扩展管理页打开本扩展的详情，启用「允许访问文件网址」。之后刷新本地页面即可。

扩展刚刚重新加载，旧标签页没反应？

点一下工具栏图标，扩展会按需向当前标签页注入内容脚本；也可以直接刷新页面。

怎么完全恢复默认？

页面内完整设置的底部有「恢复默认」。扩展级开关和暂停站点可以在本页修改。卸载扩展会清除全部本地数据。
